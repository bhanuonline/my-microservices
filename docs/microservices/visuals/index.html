What's here?

Hand-crafted HTML pages with live-rendered Mermaid diagrams. Open any file directly in a browser, or browse via make docs-serve at http://localhost:8000/my-microservices/visuals/.

Scope: Nano mode only for now. Other modes (minimal, shared-db, full) coming later.

Why HTML (not Markdown)?

Markdown Mermaid blocks (in docs/microservices/diagrams/) render fine for simple cases. These HTML pages add:

  • Color-coded panels with a consistent dark palette
  • Side panels with explanations next to diagrams
  • Interactive Mermaid with pan/zoom and clickable nodes
  • Standalone-friendly — share a single .html file over Slack / email, no renderer required
Both exist on purpose. Markdown Mermaid for in-doc context; standalone HTML for presentations, screenshots, and sharing.
