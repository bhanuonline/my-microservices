Visual Tour

A guided walk through nano mode in 8 pages — architecture first, then startup order, then four runtime request flows.

How to use this tour

Each page builds on the previous. Pick a track:

  • Linear — click Next at the bottom of each page. Takes ~30 min end-to-end.
  • Jump around — use the sidebar on the left. Each page is self-contained.
Already running? If make up-nano is up, keep docker compose ps open in another tab while reading. Match what you see live against the diagrams.

The 8-page tour

# Page What you'll learn Time
1 📊 Overview You're here. The map of the whole tour. 2 min
2 🏗 Nano topology The 7 containers, grouped by role. 5 min
3 🔗 Service dependencies Which services call which. "If I stop X, what breaks?" 4 min

Total: ~33 min. First 4 pages = architecture. Last 4 = runtime flows.

Scope

This tour covers nano mode only (make up-nano, 7 containers, ~1.6 GB RAM). The request-flow pages assume you've started the relevant business service via make debug-user / debug-product / debug-order / debug-payment alongside nano.

Visual tours for other modes (minimal, full, individual) will come later.
