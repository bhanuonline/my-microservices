How to read these pages

These 4 pages are a guided tour of nano mode (the 7-container platform). Read them in order:

  1. Overview (this page) — the big picture + how to use the tour.
  2. Architecture — what runs in nano mode and why each container exists.
  3. Startup order — the healthcheck-gated sequence Compose follows to bring everything up.
  4. Request flow — a single API call traced through every hop.
Already running? If make up-nano is up, keep docker compose ps open in another tab while reading. Match what you see live against the diagrams.

Scope

This tour covers nano mode only (make up-nano, 7 containers, ~1.6 GB RAM). Other modes have more containers and more complex flows:

  • Minimal (make up-minimal) — nano + 4 business services + Prometheus/Grafana
  • Full (make up) — minimal + Zipkin + Kafka UI + Loki + Vault + Elasticsearch
  • Individual (make up-individual) — full + 4 per-service MySQLs

Visual tours for those modes will come later.
