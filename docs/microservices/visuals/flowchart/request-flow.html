👤 User API — Request Flow

Step 6 of 9 — GET /api/v1/users from curl all the way to MySQL and back.

sync HTTP ~20-40ms warm 10 hops

The full lifecycle

Every request hops through gateway → auth → eureka → service → database. This is the happy path.

sequenceDiagram autonumber participant C as Browser / curl participant G as api-gateway :8080 participant A as auth-server :8095 participant E as eureka :8761 participant U as user-service :8081 participant M as mysql-shared :3306 C->>G: GET /api/v1/users (Basic admin:admin123) activate G G->>A: Validate JWT A-->>G: ✓ JWT valid, roles=[ADMIN] G->>E: Lookup USER-SERVICE instances E-->>G: [localhost:8081] G->>U: GET /users (proxied) activate U U->>M: SELECT * FROM user LIMIT 20 activate M M-->>U: 20 rows deactivate M U-->>G: JSON array deactivate U G-->>C: 200 OK + JSON body deactivate G Note over C,M: Total latency ~20-40ms warm, ~200ms cold

Step-by-step

#HopWhat happensIf it fails
1curl → gatewayHTTP lands on Netty listenerConnection refused — gateway down
2-3gateway → authValidates Basic auth header401 Unauthorized
4-5gateway → eurekaAsks for USER-SERVICE instances (cached ~30s)503 — user-service not registered
6gateway → user-serviceProxied HTTP, strips /api/v1 prefixTimeout or 500 if unhealthy
7-8user → mysqlHibernate query via HikariCP pool500 if DB connection broken
9-10response unwindsJSON serialization at each hop—

Observability touchpoints

  • Correlation ID: Gateway stamps X-Correlation-Id; every downstream log line carries it. Grep by it to trace one request.
  • Tracing: OFF in nano (MANAGEMENT_TRACING_ENABLED=false). Use make up-nano-trace for Zipkin at :9411.
  • Metrics: Each service exposes /actuator/prometheus. Prometheus scrapes every 15s if running (minimal+ modes).

Reproduce it for real

# Prereq: nano running + user-service running
make up-nano
make debug-user   # separate terminal

# Hit it:
curl -u admin:admin123 http://localhost:8080/api/v1/users

# Watch the hops in the logs:
docker compose logs -f api-gateway auth-server
tail -f logs/user-service-debug.log
