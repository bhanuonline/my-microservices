Call types

Sync HTTP

  • Gateway → business service — request/response, caller waits
  • Gateway → auth-server — JWT validation (cached briefly)
  • order-service → product-service — stock availability check

Async Kafka

  • order → Kafka → product — reserve-stock command
  • order → Kafka → payment — charge-payment command
  • payment → Kafka → order — payment succeeded/failed reply
  • order → Kafka → notification — notify-user event
Checkout stuck? Check order-service → product-service (sync) and order-service → Kafka → payment-service (async). Use make kafka-group-describe GROUP=order-saga to see if lag is growing.
Gateway 401 on everything? The diagram points at gateway → auth-server. Check docker compose logs auth-server first.
