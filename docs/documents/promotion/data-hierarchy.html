How to read this: Each layer extends the one below it. Layer 1 is a generic rule engine. Layer 2 adds commerce awareness. Layer 3 adds promotion logic. Layer 4 is what your team built — concepts, brands, devices, card BINs, custom vouchers, and custom restrictions. Start learning from the top (Layer 4) and only go deeper when you need to.
