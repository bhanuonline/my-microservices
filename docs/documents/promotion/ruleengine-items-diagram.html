What does KIE mean?

KIE = Knowledge Is Everything

It's just the name of the Drools project. They put "KIE" in front of normal words. So:

KIEModule = Rule Module (container) KIEBase = Rule Base (group of rules) KIESession = Rule Session (runtime)

How to remember — TV analogy

📺
KIEModule = The TV set — the whole thing. You have one.
│
📚
KIEBase = A channel package — Sports, Movies, News. Groups related channels (rules).
│
▶️
KIESession = Turning the TV ON — the act of actually watching/running.
│
📜
DroolsRule = A single channel — one individual rule.
│
🆗
RuleEngineContext = The remote control — entry point, controls which session + safety limit.
