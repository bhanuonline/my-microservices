1. Install ngrokbrew install ngrok2. Add your authtoken (one-time setup)Sign up free at https://dashboard.ngrok.com/signup if you haven't, then grab your token from:https://dashboard.ngrok.com/get-started/your-authtokenThen run:ngrok config add-authtoken YOUR_TOKEN_HERE3. Make sure your app is running on port 9010Check it's actually up, e.g. by visiting http://localhost:9010 in your browser first.4. Start the tunnel   ngrok http 90105. Copy the public URLYou'll see something like:Forwarding    https://xxxx-xx-xx-xxx-xx.ngrok-free.app -> http://localhost:9010
